AI Search Prototype

Pick a version to try.

Each version shares the same chrome and the same mock backend (window.mockSearch) but explores a different shape for the AI search experience.

v1

Spotlight modal

Hero / header pill / ⌘K opens a centered modal. Plan checklist, streamed answer, citation chips, source rail, follow-ups, shareable URL.

v2

Inline answer

No modal — the hero search submits and the answer renders directly on the page beneath it. Same backend, different UX shape.

v3

Tabs (Search + Ask AI)

Same spotlight, two modes. Search runs the classic live keyword match against the KB; Ask AI is the agentic flow. One input, switch with a tab.
